# Earlier mini-p1d prototype

This folder is an earlier skewer prototype, copied unchanged from an archived
mini-p1d bundle (commit `ef9992c`).

The combined pipeline used for the forecast lives in `p1d/` at the
repository root. That package keeps the Eisenstein-Hu spectrum, the Kaiser
`P_1D`, and the alpha-beta-gamma-delta bend, and it incorporates this
prototype's power-table rescaling, projection check, and optical-depth FGPA
skewers.
